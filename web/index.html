Wire to wire: one thread versus the three-thread pipeline

Decode, match and encode every output. With about 20 ns of work per message, handing each message across two queues costs more than it saves, so the pipeline is slower at peak. It is reported because it is true; DESIGN.md explains when the pipeline pays off.

Pipeline latency at fixed arrival rates, nanoseconds

Open loop: measured from each message's scheduled send time to publication, so stalls are counted rather than hidden.

Market-making study on synthetic flow

An Avellaneda-Stoikov quoter and a symmetric baseline with the same spread, run through the engine against the same synthetic order flow (which includes informed traders). This is a model study, not a trading result: there are no fees, no competing market makers and the flow does not react to the quotes.
